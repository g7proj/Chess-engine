These plans are the implementation half of the [documentation index](../README.md). Teaching guides live beside this folder, not here.

These plans describe the intended implementation order. Each plan should define scope, dependencies, tests, and measurable completion criteria.

Implement plans in order unless profiling or a correctness issue justifies a change. Update the roadmap and the relevant plan when scope or status changes.
